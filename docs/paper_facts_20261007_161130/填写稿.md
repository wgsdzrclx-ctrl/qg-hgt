**实际质量描述、质量目标、β 和归一化/裁剪：** Sensor 的六维描述为：当前窗口缺失率；相邻均有效点的一阶差分总体方差；去均值后 rFFT 非 DC 频率中后半部分能量占比；末值相对前最多 10 个历史点均值的绝对偏差（除以历史标准差）；有效相邻点重复值比例（容差 1e-6）；timestamp_delay/1.0。描述计算中缺失点用本窗口有效均值填充以计算频谱，epsilon=1e-8。**实际 TEP dataset 不提供 timestamp_delay，因此第六维在当前管线固定为 0，不能写成实际测得时间戳延迟。** 未实现重构误差作为描述。

`r_j=sigmoid(MLP_q(LayerNorm(a_j)))`。质量目标：

`q*_j = clip(1 - 0.25*(min(|σ|/0.4,1) + min(m_actual/0.4,1) + min(|a|/0.01,1) + min(|δ|/8,1)), 0, 1)`。

m_actual 为执行全部操作之后 observed_mask 的缺失比例，不是直接用配置概率。随机和连续缺失共用这一项。q* 仅附加到 train 样本；val/test 不含 q*，退化参数及 components 不作为模型输入。实际 L_q 是 41 个 Sensor 的 MSE；Actuator 和 Process Unit 的传播可靠性固定为 1。虽然训练图保存三类 quality_target，QCHGT 没有对后两类做可学习质量监督。对应旧框架 §4.4–4.5。

**一致性正负关系对、比例与损失：** 正样本为同图真实有向关系的源/目标节点投影。c_ij 为关系条件 MLP 经 sigmoid 的输出，输入为 source、target、relation embedding、绝对差，维数 3×64+16=208。负样本每条正边各构造：一个非邻居目标、批内下一张图的对应目标节点、目标窗口 edge padding 后向后错位 3 个采样点的特征。一般训练 batch 下正:负数量为 1:3；跨图是“不同窗口或 run”，没有强制另一个 run，也不通过故障标签挑负样本。非邻居候选是批图中该类型全部非邻居，未限在同一张图内。

损失为 BCEWithLogits，`L_c(relation)=0.5*(mean(BCE_positive)+mean(BCE_all_negatives))`，再对关系和层分别平均；因此正负总损失各占一半，不是对所有 1:3 样本直接等权平均。缺少可用负样本机制时实际负样本数减少。不使用 InfoNCE。对应 §4.6。

**类型内池化、分类损失及不平衡处理：** 分别对 Sensor / Process Unit / Actuator 做 mean pool，按该顺序拼接（192 维）后分类。分类损失普通未加权交叉熵，未使用 focal loss、类别加权或 weighted sampler。预算按源 fault_id 平衡，不等于按最终窗口 y 严格平衡，因为测试故障 run 的故障前窗口可标为 0。全模型 `L=L_cls+0.5 L_q+0.2 L_c`。对应 §4.8。

## 退化与两个协议

**退化子类型、四档强度、单位、注入范围：**

数据采样间隔为 **3 分钟（180 秒）**，窗口长度为 **W=30 个采样点**。下表中的时间长度按“采样点数×采样间隔”换算。

| 类别       | 实际子类型           | 四档数值                    | 单位与实现                                                   |
| ---------- | -------------------- | --------------------------- | ------------------------------------------------------------ |
| Noise      | `gaussian_noise`     | 0.05、0.10、0.20、0.40      | σ 为所选变量原始数值单位下的标准差；逐点独立加入 N(0,σ²) 噪声，不是相对标准差、百分比或 SNR。 |
| Missing    | `random_missing`     | 0.05、0.10、0.20、0.40      | 无量纲配置比例；每个目标变量在 W 个采样点中随机、无放回选择 round(W×rate) 个点遮蔽，缺失位置填 0 并保留观测掩码。 |
| Missing    | `continuous_missing` | 3、6、9、12                 | 连续缺失采样点数，起点均匀随机；W=30 时对应缺失比例 10%、20%、30%、40%，按采样间隔计对应 **9、18、27、36 分钟**的连续缺测长度。缺失位置填 0 并保留观测掩码。 |

| Time Shift | `time_shift`         | 1、2、4、8                  | 偏移采样点数，分别对应 **3、6、12、24 分钟**；在窗口内取 x(t−δ)，越界位置以边界值填充，无循环回绕。 |

每个退化窗口首先从整数集合 {1,2,3,4,5} 中等概率抽取目标变量数量，再从全部 52 个变量中无放回均匀抽取对应索引；`include/exclude` 均为空。因此，每窗受退化影响的变量比例约为 **1.92%–9.62%**，不是固定的传感器比例，也可能包含 Actuator。

组合退化中的多个操作共用该组变量，并按 YAML 中规定的顺序执行；过程单元特征随后根据退化后的变量重新计算。噪声、漂移和时间偏移在整个选中窗口范围内执行，连续缺失仅覆盖随机选定的连续片段。

对于随机缺失，W=30 时四档配置实际遮蔽 **2、3、6、12 个采样点**，对应实际缺失比例 **6.67%、10%、20%、40%**。因此，第一档应称为“配置缺失率 5%”，不能表述为窗口内恰好缺失 5%。随机缺失点通常不连续，不将其描述为一段连续缺测时长。

52 个变量具有不同的原始物理单位，噪声标准差和漂移速率应随目标变量解释，不能统一写成温度或压力单位。当前漂移从每个窗口起点重新累计，时间偏移采用窗口内边界填充；二者分别属于窗口级人工退化，不代表整条 run 持续累计的漂移或实际测得的通信延迟。

**Avg. Robustness 的退化集合 D、数量 K 与权重：**

Avg. Robustness 报告协议一中五个退化子类型的平均 Macro-F1。退化集合定义为：

$ D=\{\text{Gaussian Noise},\text{Random Missing}, \text{Continuous Missing},\text{Drift},\text{Time Shift}\}, \qquad K=|D|=5. $

五个子类型等权，每类权重为 \(1/5\)；每个子类型内部的四档强度等权，每档权重为 \(1/4\)。对模型 \(m\)、随机种子 \(s\)，计算：

$ R_{m,s} =\frac{1}{5}\sum_{d\in D} \left(\frac{1}{4}\sum_{\ell=1}^{4} \mathrm{MacroF1}_{m,s,d,\ell}\right). $

即每个 seed 的 **20 个单一退化测试条件等权平均**，不包含 Clean 或混合退化。随后对 seed=0/1/2/3/4 的五个 \(R_{m,s}\) 计算均值及样本标准差（ddof=1），不直接平均各条件的标准差。

根据协议一已完成的实验结果，得到：

| 模型   | Avg. Robustness（Macro-F1，0–1） |
| ------ | -------------------------------- |
| CNN    | **0.565289 ± 0.008120**          |
| GCN    | 0.140202 ± 0.018413              |
| HGT    | 0.423440 ± 0.028756              |
| QC-HGT | 0.432680 ± 0.029339              |

Table I 的 **Missing** 列仍合并随机缺失与连续缺失，因此计算 Avg. Robustness 时，Missing 列占 \(2/5\)，其他三个退化列各占 \(1/5\)。在每个 seed 内等价于：

$ R_{m,s} =\frac{\mathrm{Noise}_{m,s} +2\,\mathrm{Missing}_{m,s} +\mathrm{Drift}_{m,s} +\mathrm{TimeShift}_{m,s}}{5}. $

这里 \(K=5\) 指退化子类型数量，与故障分类的 21 类不同；该指标是等权算术平均，不是归一化 AUC。

**P1 训练/测试：** train 和 val 均 clean；每个模型每 seed 训练一次，最佳 checkpoint 在 clean 及五个操作×四强度上测试，退化评测不重新训练。当前 runner 还额外保存 `protocol_group=clean` 与随机 `degraded_single`，所以每个完成 JSON 有 23 个场景，Table I 不重复计入额外两项。

**P1 模型：** CNN、GCN、HGT、QC-HGT。

**P1 训练监督细节：** 无人工输入退化的 clean 窗口也附加质量目标；若原始数据完整，则各变量 q*=1，质量分支以此做 MSE；若源窗口有非有限观测，质量目标还会按其 mask 缺失率扣分，不能未经全量检查宣称全部 q*=1。L_c 的真实边及错连/跨图/3 点时间错位负对仍生成并参与训练；这些是辅助关系监督，不是将 P1 分类训练改为混合退化。P1 QC-HGT 损失权重保持 1/0.5/0.2。

**P2 训练/测试：** train 随机混合退化，val 使用同一已见组合和强度分布；test 输出 Clean、Seen Degradation、Unseen Combination。clean 测试通过显式 clean grid rule 构造。runner 另外评测单一退化四档供曲线使用；这些额外最高强度不属于 Table II 的 unseen_combination。

**P2 训练混合分布、组合、强度及采样比例：** 每窗以 0.8 概率注入，以 0.2 概率保持 clean。注入条件下，六种组合等概率 1/6：Noise、Drift、Random Missing、Continuous Missing、Time Shift、Noise+Random Missing，因此各组合的无条件概率为 0.8/6≈13.33%。每个操作的强度从下列三个值等概率抽取；组合中的强度分别抽取。

- gaussian_noise=[0.05,0.10,0.20]
- drift=[0.001,0.0025,0.005]
- random_missing=[0.05,0.10,0.20]
- continuous_missing=[3,6,9]
- time_shift=[1,2,4]

每 epoch 的 train 退化根据 seed、split、epoch、run_uid 和窗口边界确定性更新；val epoch 保持 0，因而同 seed 下验证退化固定。

**P2 Seen Degradation 测试集合与汇总权重：** `protocol_group=known`，每窗注入概率 1.0，六组合与三档强度同训练，组合等概率 1/6、各强度等概率 1/3。2000 个测试窗口每个生成一个随机退化样本，直接对整个组计算一次 21 类 Macro-F1；不是穷举六组合×全部强度后平均各个 Macro-F1。实际实现对组内样本等权，类别 F1 再等权；随机抽样比例不保证有限样本严格相等。

**P2 Unseen Combination 保留组合、强度及权重：**测试场景为 `protocol_group=unseen_combination`，保留三个训练和验证中均未出现的组合：Drift + Time Shift、Noise + Continuous Missing、Random Missing + Time Shift。每个测试窗口以 1/3 的概率抽取其中一个组合，退化注入概率为 1.0。各操作的强度集合与训练完全一致，并在各自三档强度中独立、均匀抽样，因此测试考察的是未知组合泛化，而非单项退化强度外推。三个组合在有限测试集中的实际数量不要求严格相等。每个 seed 在全部 2000 个测试窗口上统一计算组级 Macro-F1，不分别计算三个组合的分数再等权平均；最终报告五个 seed 的均值±标准差。早停和最佳 checkpoint 选择仅依据验证集 Macro-F1，未知组合测试集不参与上述选择。

**术语对应：** 图中的 Unseen Mixed、Table II 的 Unseen Combination 均应指 `protocol_group=unseen_combination` 同一测试集合。

**P2 模型/消融实现：**

| 名称 | 质量注意力 | 一致性注意力 | L_q 有效权重 | L_c 有效权重 | 骨干 |
| --- | --- | --- | ---: | ---: | --- |
| HGT | 无 | 无 | 0 | 0 | 原生 PyG HGTConv |
| HGT + Quality | 开 | 关 | 0.5 | 0 | 自定义 QCHGT |
| HGT + Consistency | 关 | 开 | 0 | 0.2 | 自定义 QCHGT |
| QC-HGT | 开 | 开 | 0.5 | 0.2 | 自定义 QCHGT |

质量注意力项为 λ_r log(r_source+1e-8)，一致性项为 γ_r c_source,target，按关系、按目标邻居 softmax。关闭开关会消除对应注意力项及有效辅助损失权重，但当前 QCHGT.forward 仍实例化/计算质量分支和一致性分支（包括禁用项的原始损失）；不能写成物理删除分支或计算量随开关完全消失。尤其 Quality Only 仍会计算不参与总损失的一致性量。

**公平性设置：** 当前配置同协议共享 run 划分、窗口抽样及预算、seed 集合、退化规则、学习率/优化器/batch/epoch上限/早停规则；同一 seed、同一窗口的退化由局部 RNG 保证跨模型一致，跨 seed 的退化随机实现可不同。CNN 使用原始窗口及窗口标准化，图模型使用统计输入；HGT 与三个自定义模型在注意力结构、激活、dropout 和参数量上存在差异。因此现有 Table II 可报告模块对照，但**不能声称四行都是同一骨干的严格纯模块消融**；其中两个单模块变体与完整 QC-HGT 才共用自定义骨干。模型调参搜索范围、试验次数及预算是否相等：当前正式实验使用 YAML 中固定的模型配置，未启用自动超参数搜索或参数敏感性扫描；每个模型在每个协议下按固定配置运行 seed=0/1/2/3/4，五次运行用于评估随机性，不属于超参数搜索。各模型共享训练窗口预算及训练规则：训练窗口数 5000、AdamW、学习率 0.001、权重衰减 0.0001、batch size 128、最多 30 个 epoch，以验证集 Macro-F1 选择 checkpoint，早停 patience=5、min_delta=0.0001。上述设置统一的是训练资源上限和停止规则，不保证实际训练轮数、运行时间或计算量相同。正式配置确定前的人工调参范围、候选配置数量及累计搜索预算缺少完整记录，无法确认各模型是否相等。
